#Daily task tracker
features included:
1.Add a new task
2.Edit an existing task
3.Delete a task
4.Mark task as completed with a badge
5.Responsive UI using Bootstrap



******Instructions
1. Enter a task in the input field → Click Add Task
2 .Click Edit to modify a task
3. Click Delete to remove a task
4 .Check the box to mark a task as completed → Edit button disappears and a Completed badge appears
